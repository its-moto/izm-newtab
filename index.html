ハードウェア詳細

温度などを見るには LibreHardwareMonitor（v0.9.5 以降）が必要です。

  1. 公式の GitHub から最新版を入れて、管理者として起動
  2. Options → Remote Web Server → Run（Interface / Port は 0.0.0.0 のまま）
  3. グラフを細かく動かすなら、Options → Update Interval → 250ms
  4. Windows のファイアウォールの確認が出たら、どちらにもチェックを入れずにキャンセル（ほかの PC から見られないように）

セキュリティソフトが警告した場合は、除外設定はせずに使うのをやめてください。
