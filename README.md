# 出雲式新しいタブ！！

Chrome / Edge の「新しいタブ」を、時計・時間割・天気・地震情報・システムモニターなどが並ぶダッシュボードに置き換える自作の拡張機能です。
テーマカラーを1色選ぶだけで、全体の色がまとめて変わります。

## 主な機能

### 毎日使うもの
- **時計・日付**
- **Google 検索ボックス**
- **ショートカット**：最大9個まで登録できます。ドラッグで並べ替えられます。
- **時間割**（月〜土・5限）
  - 今日の曜日の列が色付きになります。
  - JSON で書き出し（EXPORT）と読み込み（IMPORT）ができます。
- **電卓**：キーボードでも入力できます。
- **関数電卓**（電卓の `fx` から開きます）
  - 三角関数（DEG / RAD）、逆三角関数、双曲線関数、対数、累乗根、階乗、nCr / nPr など
  - 分数のまま誤差なく計算し、分数 ⇔ 小数を切り替えられます（`1/3 + 1/6 = 1/2`）。
  - 微分を式のまま計算します（`diff(x^2 sin x, x)` → `2x·sin(x) + x²·cos(x)`）。値も出せます（`diff(x^3, x, 2)` → `12`）。
  - 定積分・総和・総乗の値を出します（`int(sin x, x, 0, π)`、`sum(k^2, k, 1, 10)`、`prod(k, k, 1, 5)`）。
  - TeX を貼り付けるとそのまま計算できます（`\frac`、`\sqrt`、`\int_a^b … dx`、`\sum`、`\frac{d}{dx}` など）。結果を TeX でコピーすることもできます。
  - `x` を含む式はグラフで表示できます（ホイールで拡大、ドラッグで移動、ダブルクリックで元に戻す）。
  - `a = 2/3` のように変数に代入でき、`ans` で前の答えを使えます。

### 情報
- **天気**（Open-Meteo）
  - 現在地の天気と、3時間ごとの予報を表示します。
  - 位置情報が使えないときは、決まった座標の天気を出します。
- **気象警報・注意報**（気象庁）
  - 現在地の市区町村に出ている警報・注意報を、天気の横にバッジで表示します（例：[雷][大雨]）。
- **地震情報**（気象庁＋Wolfx）
  - 最近の地震を最大10件表示します。
  - 緊急地震速報が出たときは、一番上に表示します。
  - 最大震度で絞り込めます。

### システム
- **システムモニター**
  - CPU とメモリの使用率を心電図風のグラフで表示します。
  - OS、CPU の名前とスレッド数、コアごとの使用率も出します。
  - 「詳細」ボタンでハードウェア詳細のパネルが開きます。
    - CPU・メモリの使用率とコアごとの使用率を、直近1分のグラフで表示します。
    - [LibreHardwareMonitor](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor) を入れていると、温度・GPU使用率・消費電力・クロック・ネットワーク・ストレージの読み書きのグラフと、機器ごとの詳しい値も表示します。
- **回線速度**（Cloudflare）
  - 計測結果を記録して、履歴をグラフにします。
  - 接続状態と Ping も表示します。
- **保存データ・ダウンロード**
  - この拡張機能が使っている保存容量を表示します。
  - 進行中のダウンロードの進み具合も見られます。
- **バッテリー**
  - 残量と、残り時間・満充電までの時間を表示します。
  - Windows ではブラウザが残り時間を教えてくれないため、残量の減り方から推定しています。

### 見た目
- **テーマカラー**：全体の色と、タブのアイコンの模様が変わります。
- **サブカラー**：パネルの背景色と濃さを変えられます。テーマカラーを暗い色にしたときは、明るいサブカラーにすると読みやすくなります。
- **背景**
  - 動画か画像を設定できます。
  - 背景の不透明度を変えられます。
  - 動画のときは音量も変えられます。音量は覚えておきますが、開くたびにミュートから始まります。

## インストール

1. [Releases](https://github.com/its-moto/izm-newtab/releases) から最新版の **Source code (zip)** をダウンロードし、展開します。
2. ブラウザの拡張機能ページを開きます。
   - Chrome：`chrome://extensions`
   - Edge：`edge://extensions`
3. **デベロッパーモード**（Edge では「開発者モード」）をオンにします。
4. **パッケージ化されていない拡張機能を読み込む**（Edge では「展開して読み込み」）を押し、展開したフォルダーを選びます。
5. 新しいタブを開くと IZM-NewTab が表示されます。

> [!IMPORTANT]
> 拡張機能を読み込んだフォルダーは、移動・削除しないでください。
> ブラウザはフォルダーの場所で拡張機能を区別しているため、場所が変わると時間割・ショートカット・背景などの設定が引き継がれません。

## アップデート

新しいバージョンがあると、新しいタブの左下にお知らせが出ます。

1. 拡張機能のフォルダーにある **`update.bat`** をダブルクリックします。
   - 最新版をダウンロードして、今のフォルダーに上書きします。設定はそのまま残ります。
2. 新しいタブの更新パネルにある **拡張機能を再読み込み** を押します。

`update.bat` が使えないときは、最新版の ZIP を展開し、中のファイルを今のフォルダーに上書きしてから、拡張機能ページで再読み込みしてください。

> [!NOTE]
> v1.1.1 以前から更新するときは、まだ `update.bat` がないため、一度だけ手動で上書きしてください。

## 権限と外部サービス

### 権限

| 権限 | 使い道 |
| --- | --- |
| `system.cpu` / `system.memory` | システムモニターの CPU・メモリ使用率 |
| `downloads` | ダウンロードの進み具合の表示、更新用 ZIP のダウンロード |
| 位置情報（ブラウザで許可した場合のみ） | 天気と気象警報の地域を決める |
| `http://localhost/*` | LibreHardwareMonitor から温度などを読む（自分の PC の中だけ） |

### 外部サービス

データの取得に、次のサービスを使っています。どれもキーは不要です。
外部に送っているのは、天気・警報を調べるための緯度経度と、ショートカットのアイコンを取るためのドメイン名だけです。時間割などの設定は送っていません。

| サービス | 使い道 |
| --- | --- |
| [Open-Meteo](https://open-meteo.com/) | 天気・予報 |
| [気象庁](https://www.jma.go.jp/) | 地震の一覧、気象警報・注意報、地域コード |
| [Wolfx Open API](https://wolfx.jp/) | 緊急地震速報（WebSocket） |
| [国土地理院 逆ジオコーダー](https://maps.gsi.go.jp/) | 緯度経度から市区町村を調べる |
| [Cloudflare Speed Test](https://speed.cloudflare.com/) | 回線速度の計測、Ping |
| Google（favicon） | ショートカットのアイコン |
| GitHub | 新しいバージョンの確認 |
| LibreHardwareMonitor（自分の PC） | 温度・消費電力などのセンサー情報（入れている人のみ） |

> [!WARNING]
> 地震情報・緊急地震速報は、外部のデータをそのまま表示しているだけです。
> 遅れたり、届かなかったりすることがあります。防災には、公式の情報や専用のアプリを使ってください。

## 温度などの詳細を見るには

拡張機能だけでは温度を読めないため、LibreHardwareMonitor の Web サーバー機能を使います。

1. [LibreHardwareMonitor](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor/releases) の **v0.9.5 以降**を公式の GitHub から入れて、**管理者として**起動します（CPU の温度を読むのに必要です）。
   - v0.9.4 以前は、Microsoft Defender が警告する古いドライバー（WinRing0）を使っているので使わないでください。
2. メニューの **Options → Remote Web Server → Run** をオンにします。
   - **Interface / Port** は **0.0.0.0** のままにしてください。ほかのアドレスにすると、新しいタブ（localhost）からつながらなくなります。
3. Windows のファイアウォールの確認が出たら、**プライベート・パブリックのどちらにもチェックを入れずにキャンセル**します。
   - Web サーバーはネットワーク全体で待ち受けるため、許可するとほかの PC からもセンサー情報が見えてしまいます。キャンセルしても、同じ PC の新しいタブからは読めます。
4. 新しいタブのシステムパネルにある **詳細** を押すと、ハードウェア詳細のパネルが開きます。接続できると、ボタンに ● が付きます。

> [!CAUTION]
> セキュリティソフトが LibreHardwareMonitor を警告した場合は、除外設定をせずに使うのをやめてください。

ポートを 8085 から変えている場合は、詳細パネルでポート番号を入力して「再接続」を押してください。

グラフを細かく動かしたい場合は、LibreHardwareMonitor の **Options → Update Interval** を **250ms** にしてください（初期設定の 1s だと1秒ごとにしか値が変わりません）。

## 保存されるデータ

設定は、すべてブラウザの中（この拡張機能の localStorage と IndexedDB）に保存されます。

- **localStorage**：時間割、ショートカット、テーマカラー、不透明度、音量、震度フィルター、回線速度の記録など
- **IndexedDB**：背景の動画・画像と、動画の再生位置

拡張機能を削除すると、これらのデータも消えます。
時間割は EXPORT でファイルに書き出しておけます。

## フォルダー構成

```
newtab/
├── manifest.json        拡張機能の設定（バージョンはここで管理）
├── version.json         最新バージョンと更新内容（GitHub 上のものを最新版として参照）
├── index.html           新しいタブの本体
├── update.bat           アップデート用（tools/update.ps1 を起動）
├── tools/
│   └── update.ps1       最新版をダウンロードして上書きするスクリプト
└── assets/
    ├── css/styles.css
    ├── fonts/           ドットフォント
    ├── icons/
    └── script/          機能ごとの JavaScript
```

## リリースの手順（開発者向け）

1. `manifest.json` の `version` を上げます。
2. `version.json` の `version` と `message` を書き換えます。
   - `message` は改行区切りで書きます。
   - 更新パネルと `update.bat` の画面に、そのまま箇条書きで表示されます。
3. `れどめ.txt` の更新履歴にも追記します。
4. main に push し、GitHub で Release を作ります。

画面左下のバージョン表示は `manifest.json` から自動で入るため、`index.html` を書き換える必要はありません。
